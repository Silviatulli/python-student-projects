# Python Student Projects

Website showcasing the final data science projects of students in the **Basic Python** and **Advanced Python** courses, published as blog posts.

Live site: https://silviatulli.github.io/python-student-projects/

## Adding a project

1. Copy `_templates/project-template.md` to `_posts/YYYY-MM-DD-short-title.md`.
2. Set `categories: basic` or `categories: advanced` in the header.
3. Put images in `assets/img/<project-name>/`.
4. Open a pull request.

Full instructions: see the [Submit page](https://silviatulli.github.io/python-student-projects/submit/).

Posts with `placeholder: true` are examples and can be deleted once real projects arrive.
